Green Remedies

Open-source team project — a fully authenticated e-commerce application for herbal products with Kinde Auth, secure checkout, and real-time inventory.

Next.js Kinde Auth Prisma PostgreSQL Open Source
// the challenge

Business Challenge

This collaborative open-source project addressed the challenge of building a secure, fully authenticated e-commerce platform from the ground up — with particular emphasis on OAuth-based authentication, role-based access control, and real-time inventory synchronisation.

// our approach

Engineering Approach

Built with Next.js and Prisma ORM, the application uses Kinde Auth for passwordless authentication and social login. A PostgreSQL database with Prisma migrations manages product catalogue, inventory, and order state. Role-based middleware controls access to admin dashboards, order management, and inventory tools. Real-time inventory updates prevent overselling through optimistic locking patterns.

Business Results & Metrics

  • Secure Authentication
    Passwordless and social login via Kinde Auth, with role-based access control for admin and customer user types.
  • Real-Time Inventory
    Optimistic locking prevents overselling, with inventory counts updating in real time across concurrent sessions.
  • Open-Source Collaboration
    Published as an open-source project with documented API contracts, enabling community contributions and code review.
