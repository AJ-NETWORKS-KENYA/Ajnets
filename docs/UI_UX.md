## 1. Visual Language & Tokens

| Token | Hex / HSL | Usage |
| --- | --- | --- |
| **Primary Blue** | `#43baff` | Main call-to-actions, link hovers, active accents |
| **Secondary Purple** | `#7141b1` | Secondary highlights, blockquote borders, badge accents |
| **Dark Navy** | `#141d38` | Deep header background, dark sections |
| **Heading Dark** | `#1b1d21` | Headings `h1`–`h6` |
| **Body Copy** | `#6d6d6d` | Body text and descriptions |
| **Light BG** | `#f8f8f8` | Section contrast backgrounds |

## 2. Typography
- **Primary Font Family:** Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Heading Styles:** Bold weight (700), crisp line heights (1.2–1.35)
- **Body Styles:** Regular weight (400), line height 1.6 for enhanced readability

## 3. UI Components & Layouts
- **Header:** Glassmorphism blurred navbar with logo and responsive toggle menu.
- **Hero Sections:** High-impact headings, gradient text accents, dual CTAs.
- **Card Systems:** Hover lift animations, border glow effects, distinct iconography.
- **Footer:** Deep navy dark theme with brand mission, sitemap links, and unified social links (`Facebook`, `LinkedIn`, `YouTube`, `Pinterest`).
