## 3. Typography Hierarchy

* **Primary Typeface:** `Montserrat` (Sans-serif)
  * Usage: Main headings (`h1`–`h6`), page titles, navigation links, bold display text.
  * Style: Bold (700) / ExtraBold (800) / Black (900).
* **Secondary Typeface:** `Nunito Sans` (Sans-serif)
  * Usage: Body text, lead paragraphs, form inputs, subtitles, micro-copy.
  * Style: Regular (400) / SemiBold (600), line-height 1.6–1.8.

---

## 4. Logo Usage & Clear Space Rules

* **Clear Space Requirement:** Always maintain a minimum clear space of **50px** around all edges of the logo to ensure visibility and legibility.
* **Minimum Size Constraint:** The logo must never be rendered smaller than **128px width (1.33 inches)**. Below this threshold, visual detail is lost.
